# 恩希上架工具

給內勤員工用的「填空式」電商上架輔助工具。手機優先。

員工只要：**填空 → 按產生 → 複製**，就能拿到：
- 可貼到蝦皮 / Momo 的上架文案指令（標題、內文）
- 可貼到 GPT 的製圖指令

> 生圖引擎照舊是 ChatGPT：本工具只產 prompt，不呼叫任何生圖 API。

## 兩種模式

### ⚡ 白牌九圖（預設）——一條龍：製圖＋文案＋定價

上傳素材＋填規格 →**勾一次策略**→ 按一顆按鈕 → 得到八張製圖 prompt＋選項圖工作單，逐張複製貼給 GPT 生圖。頂部一條龍導航（素材資料 → 製圖 → 文案 → 定價），完成的區塊自動打勾。

**v2 哲學翻轉（重要）**：實測發現「兩百行死規格（hex 色碼、字級倍數、座標）反而把 GPT 綁死、產出塑膠感」。v2 把 Hero 從「死規格」改成「**策略簡報**」——工具只講策略（品類／主賣點／關鍵動作／TA／調性），**配色、排版、質感的發揮權還給 GPT**。

- **策略勾選卡**：分析完，員工勾一次（主打賣點／主標／關鍵動作／賣給誰／調性），這套策略貫穿全部圖。改任一勾選 → 全部即時重組（純前端、零 API）。
- **不再注入 hex**：連貫性靠九張共用「**同一句調性描述（tone）**」，由 TA＋品類推導（`deriveTone`／`TONE_OPTIONS`），員工可下拉覆蓋。
- **戰場分級**：🔥 死磕（Hero／規格圖，值得重生到滿意）／✅ 要對（比較圖／選項圖）／🌊 放生（中間 5 張介紹/情境，指令刻意寫鬆、「充門面能看即可」）。卡片有分級標籤。
- **關鍵動作**（分析卡新增 `copy.key_action_options`）：主圖最該有的那個動作瞬間（例：製冰盒→手擠壓冰塊掉出），扣住主賣點。
- **比較圖鬆綁**：允許跟「傳統／一般款」做真實品類對比，但禁指名品牌、禁捏造數據。
- **連貫鏈 SOP**：放生圖＋比較圖的卡片紅字提醒「做下一張前，把上一張存下當風格參考圖一起傳給 GPT」——半自動架構靠 SOP 撐一致性。
- **📝 一鍵上架文案**（`/api/copy`）：後台 Claude 直接回可貼上蝦皮的成品——60 字標題（程式硬驗字數、超標自動重修）＋黃金前段＋痛點解方＋規格條列＋售後三段公板＋hashtag。禁字/格式程式把關。
- **💰 定價三條線**：填成本自動算出清（0%）／警示（15%）／建議售價（25%）／獲利（35%），費率寫死。

- 素材圖前端壓縮（長邊 ≤1024、JPEG 0.8）後送 `/api/analyze`（Cloudflare Worker → Anthropic vision），回一份分析卡 JSON：商品主色、文案素材、素材健檢、素材分工、規格轉錄、關鍵動作候選。素材圖不落地。
- 前端模板引擎 `src/nineTemplates.js`（純函式、零 AI）把分析卡＋勾選策略組成八張 prompt：Hero 策略簡報／使用方式／材質品質／細節特寫／情境 A/B／比較圖／尺寸規格圖，外加每色一張選項圖。
- 規格數字一律人填，AI 只負責排版；每張卡附「文字核對清單」。
- 有問題的素材（簡體字浮水印、他牌 logo…）縮圖會標紅 ⚠。
- **素材分工建議**：AI 順便建議「主圖／賣點圖／情境圖／規格圖／比較圖各用第幾張」，縮圖標 ⭐、卡片素材提示直接寫「用第 N 張」，員工不用自己挑圖。
- **規格轉錄提示**：AI 只「抄」圖上印的規格數字（不推測），顯示在規格欄下方「👀 圖上寫：500ml」；欄位空白時可按「帶入」一鍵填入（仍由人按、人核對），人填的值跟圖上不一致會跳黃色警告。
- **零教學上手**：頁首固定三步驟（傳圖 → 按按鈕 → 逐張貼給 GPT）＋「怎麼貼給 ChatGPT」摺疊小抄；卡片有「⬇ 存素材圖」直接下載 AI 建議的那張（免回相簿翻圖），複製後自動捲到下一張並留下「已複製」標記。
- **自動存檔**：有分析結果後，勾完成／換配色／改規格等任何變動停手 1.5 秒自動存進雲端，手滑關掉網頁也不會弄丟工作。密碼記在裝置上，不用每次重輸。
- **AI 額度控管**：每次分析的 token 花費記進 KV（按台灣時區月份歸戶），頁面顯示「本月 AI 分析額度」進度條；用滿當月上限（`wrangler.toml` 的 `ANALYZE_MONTHLY_BUDGET_TWD`，預設 NT$300）就鎖住分析按鈕，下月 1 號自動重置。已產生／已存檔的指令不受影響。

### 🗂 經典模式

原有四分頁工作流（樂扣樂扣、珍珠金屬照舊）：

1. **標題** — 貼上競品標題，產生蝦皮 + Momo 標題優化指令。
2. **內文** — 沿用商品資料，產生 80–150 字內文指令。
3. **製圖** — 選圖種（主圖 / 選項圖 / 規格圖 / 情境圖 / 使用說明），產生對應製圖指令。
4. **定價** — 成本試算。

## 技術

- Vite + React + Tailwind CSS（v4）
- Cloudflare Worker（`worker/`）：靜態檔 + `/api/products`（KV 商品儲存）+ `/api/analyze`（Anthropic vision 分析）
- `npm run build` 輸出到 `dist`

## 開發

```bash
npm install
npm run dev      # 本地開發
npm run build    # 輸出 dist/
npm run preview  # 預覽 build 結果
npm test         # 單元測試（模板引擎 + analyze schema 驗證）
```

## 白牌九圖上線前置（一次性）

1. `wrangler secret put ANTHROPIC_API_KEY` — 沒設的話 `/api/analyze` 回 503，前端會提示「後台尚未設定 AI 金鑰」。
2. 挑 1 張最會賣的爆款成品當「標準版型參考圖」，放到 `public/assets/hero-ref-1.jpg`（Hero 卡片的下載鈕會抓這個路徑）。
3. 手動打 API 驗證：`./scripts/test-analyze.sh https://你的網址 ./某張商品圖.jpg [密碼]`。
